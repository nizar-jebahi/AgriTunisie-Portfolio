**AgriTunisie** is an academic engineering project exploring the integration of Artificial Intelligence (AI), Internet of Things (IoT), and modern software technologies to address agricultural challenges.

The platform aims to support plant health monitoring, intelligent irrigation, and data-driven agricultural decision-making.

---

## Project Highlights

- **Plant Disease Detection:** Computer vision using YOLOv8.
- **Disease Classification:** Deep learning with EfficientNetB0.
- **Intelligent Irrigation:** Predictive machine learning using XGBoost.
- **IoT Monitoring:** Real-time environmental and soil data acquisition.
- **Agricultural Assistant:** A Retrieval-Augmented Generation (RAG) solution.
- **Centralized Dashboard:** An integrated interface for agricultural information.

## System Architecture

AgriTunisie combines five main technical layers:

1. Frontend — Angular and Ionic.
2. Backend — Python and FastAPI.
3. Artificial Intelligence — YOLOv8, EfficientNetB0, XGBoost, and RAG.
4. IoT — Raspberry Pi 4B and environmental sensors.
5. Database — MongoDB.
