# AgriTunisie — Project Overview

## 1. Introduction

AgriTunisie is an Agriculture 4.0 platform that explores the integration of Artificial Intelligence, Internet of Things (IoT), and modern software technologies to address agricultural challenges.

The project aims to support farmers through intelligent monitoring, plant disease analysis, and data-driven irrigation assistance.

## 2. Problem Statement

Agriculture faces several challenges that can affect productivity and resource management, particularly:

- Delayed identification of plant diseases.
- Limited access to reliable, real-time field data.
- Water scarcity and inefficient irrigation practices.
- Difficulty accessing relevant agricultural information.

These challenges highlight the need for accessible digital solutions that support more informed agricultural decisions.

## 3. Proposed Solution

AgriTunisie proposes an integrated digital platform combining AI-based analysis, IoT monitoring, and a conversational agricultural assistant.

The platform is designed to transform collected agricultural data into useful information that can support monitoring and decision-making.

## 4. Main Objectives

- Support early plant disease identification through computer vision.
- Explore predictive approaches for intelligent irrigation.
- Monitor environmental and soil conditions using IoT sensors.
- Provide accessible agricultural information through a RAG-based assistant.
- Bring agricultural monitoring and AI capabilities together in one platform.

## 5. Core Features

| Feature | Description |
|---|---|
| Plant Disease Analysis | AI-based analysis of plant images |
| Smart Irrigation | Irrigation-related predictions using environmental data |
| IoT Monitoring | Collection of soil and environmental measurements |
| Agricultural Assistant | Conversational access to agricultural knowledge |
| Dashboard | Centralized presentation of agricultural information |

## 6. Technology Stack

**Frontend**
- Angular
- Ionic

**Backend**
- Python
- FastAPI

**Artificial Intelligence**
- YOLOv8
- EfficientNetB0
- XGBoost
- Retrieval-Augmented Generation (RAG)

**IoT**
- Raspberry Pi 4B
- DHT11 temperature and humidity sensor
- BH1750 light sensor
- Capacitive soil moisture sensor
- MCP3008 analog-to-digital converter

**Database**
- MongoDB

## 7. Project Scope

AgriTunisie was developed as an academic Software Engineering project, with an interdisciplinary approach combining software development, artificial intelligence, and connected devices.

Its broader vision is to explore how digital technologies can contribute to more informed agricultural practices, particularly in environments where water management and crop monitoring are important challenges.

## 8. Project Presentation

AgriTunisie demonstrates the application of modern engineering technologies to a real-world agricultural problem.

This repository presents the project's concept, architecture, technologies, and selected documentation. The source code, trained models, and private datasets are not publicly distributed.
